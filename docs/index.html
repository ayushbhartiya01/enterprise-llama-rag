System overview

Enterprise Llama RAG

A focused document question-answering pipeline: parse PDFs, retrieve relevant passages, rerank them, check grounding, and generate an answer.

LlamaIndex LlamaParse v2 Qdrant Cohere Rerank Groq Local embeddings

01 / Components

What each service does in the current implementation.

Ingestion

LlamaParse v2

Uploads PDFs from data/, parses them to Markdown, and returns page content.

Chunking and embeddings

LlamaIndex + BGE

SentenceSplitter creates chunks; BAAI/bge-large-en-v1.5 embeds them locally.

Vector storage

Qdrant

The enterprise_collection stores vectors and their source text for retrieval.

Reranking and grounding

Cohere Rerank

Reranks retrieved candidates; a relevance threshold can reject weak context before generation.

Answer generation

Groq

openai/gpt-oss-120b generates an answer from the selected passages.

03 / Query policy and security boundary

Designed for focused questions, not bulk summarization.

Focused questions

Questions about a specific fact, policy, topic, or section can proceed through retrieval and grounding.

Broad summaries are rejected

Requests to summarize entire documents or the corpus are blocked. Narrow the request to a section, page, or topic.

RBAC is not implemented

The current app has no user authentication or document-level access controls. Every app user can query the configured collection.

Review data handling before use

PDFs are sent to LlamaCloud for parsing; queries and retrieved passages are sent to Cohere and Groq. Use only approved data and do not expose this app with confidential documents until authentication, authorization, and provider policies are reviewed.
